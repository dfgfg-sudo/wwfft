# 第二卷：Coze 平台完整指南与主页功能

## 一、Coze（扣子）主页完整功能列表

Coze（扣子）是字节跳动推出的 AI 智能体开发平台，主界面涵盖以下核心模块：

### 1. 项目开发
- 创建的智能体和应用列表都在这里
- 点击「+ 项目」可以创建智能体和应用
- 项目开发是创建智能体和应用的主入口

### 2. 资源库
- 自己创建的所有资源的集中管理入口
- 右上角点击「+ 资源」可新增各类资源
- 资源库涵盖以下全部资源类型：

| 资源类型 | 说明 |
|---------|------|
| **工作流（Workflow）** | Coze 平台最核心的功能，是一个 DAG 有向无环图，通过可视化拖拽节点将大模型、插件、代码等组件组合成自动化流程 |
| **对话流（Chatflow）** | 基于对话场景的特殊工作流，适合 Chatbot、智能客服、个人助手等场景 |
| **插件（Plugin）** | 模型的技能工具，提供联网搜索、天气查询、车票查询等各类功能 |
| **知识库（Knowledge Base）** | 支持上传 PDF、TXT、DOC、DOCX、MD 等格式文件，基于内容片段进行检索和召回 |
| **数据库（Database）** | 智能体的「记忆中枢」或「外置大脑硬盘」 |
| **记忆库（Memory）** | 保存临时用户个人信息，让 Bot 记住用户特征 |
| **提示词（Prompt）** | 用于定义 AI 的角色定位、核心技能及行为限制 |
| **音色（Voice）** | 用于语音交互场景 |
| **知识卡片（Card）** | 资源库中可创建的资源类型之一 |

### 3. 发布管理
- 包含已发布的应用、智能体和工作流的统一管理入口

### 4. 商店与社区

| 模块 | 说明 |
|------|------|
| **插件商店** | AI 的工具箱，提供丰富的官方/第三方插件资源 |
| **模板商店** | 提供大量可复制的成品智能体、工作流和应用模板，可一键复制到个人空间修改使用 |
| **作品社区** | 创作者上传的成品智能体和话题流，可一键复制后修改使用，具有社交属性 |

### 5. 其他功能模块

| 模块 | 说明 |
|------|------|
| **任务中心** | 自动化任务与批量作业管理中心 |
| **API & SDK** | 将 Coze 能力变成可被其他系统调用的标准化接口 |
| **文档与教程** | Coze 官方文档中心 |
| **模型管理** | Coze 内置的大模型和外部平台配置管理 |
| **效果评测** | 工作空间中包含的评测功能模块 |

### 6. 工作空间
- 工作空间是管理个人或团队创建的各种智能体和相关资源的虚拟空间
- 分为**个人空间**和**团队空间**

# 第二卷：Coze 平台完整指南与主页功能

## 一、Coze（扣子）主页完整功能列表

Coze（扣子）是字节跳动推出的 AI 智能体开发平台，主界面涵盖以下核心模块：

### 1. 项目开发
- 创建的智能体和应用列表都在这里
- 点击「+ 项目」可以创建智能体和应用
- 项目开发是创建智能体和应用的主入口

### 2. 资源库
- 自己创建的所有资源的集中管理入口
- 右上角点击「+ 资源」可新增各类资源
- 资源库涵盖以下全部资源类型：

| 资源类型 | 说明 |
|---------|------|
| **工作流（Workflow）** | Coze 平台最核心的功能，是一个 DAG 有向无环图，通过可视化拖拽节点将大模型、插件、代码等组件组合成自动化流程 |
| **对话流（Chatflow）** | 基于对话场景的特殊工作流，适合 Chatbot、智能客服、个人助手等场景 |
| **插件（Plugin）** | 模型的技能工具，提供联网搜索、天气查询、车票查询等各类功能 |
| **知识库（Knowledge Base）** | 支持上传 PDF、TXT、DOC、DOCX、MD 等格式文件，基于内容片段进行检索和召回 |
| **数据库（Database）** | 智能体的「记忆中枢」或「外置大脑硬盘」 |
| **记忆库（Memory）** | 保存临时用户个人信息，让 Bot 记住用户特征 |
| **提示词（Prompt）** | 用于定义 AI 的角色定位、核心技能及行为限制 |
| **音色（Voice）** | 用于语音交互场景 |
| **知识卡片（Card）** | 资源库中可创建的资源类型之一 |

### 3. 发布管理
- 包含已发布的应用、智能体和工作流的统一管理入口

### 4. 商店与社区

| 模块 | 说明 |
|------|------|
| **插件商店** | AI 的工具箱，提供丰富的官方/第三方插件资源 |
| **模板商店** | 提供大量可复制的成品智能体、工作流和应用模板，可一键复制到个人空间修改使用 |
| **作品社区** | 创作者上传的成品智能体和话题流，可一键复制后修改使用，具有社交属性 |

### 5. 其他功能模块

| 模块 | 说明 |
|------|------|
| **任务中心** | 自动化任务与批量作业管理中心，用于管理调度需要脱离实时对话、在后台自动执行的 AI 任务 |
| **API & SDK** | 将 Coze 的 AI 智能体、工作流、对话能力等核心功能变成可被其他系统调用的标准化接口 |
| **文档与教程** | Coze 官方文档中心 |
| **模型管理** | Coze 内置的大模型和外部平台配置管理 |
| **效果评测** | 工作空间中包含的评测功能模块 |

### 6. 工作空间
- 工作空间是管理个人或团队创建的各种智能体和相关资源的虚拟空间
- 分为**个人空间**和**团队空间**
