## 统一工作流设计（21个节点）

```
[开始] → [输入解析] → [条件路由] → 分支处理 → [结果聚合] → [输出] → [结束]
```

### 节点详情

| 序号 | 节点名称 | 节点类型 | 功能描述 |
|------|----------|----------|----------|
| 1 | 开始 | Start | 工作流入口，接收用户输入 |

| 3 | 条件路由 | Condition | 根据输入类型路由到对应处理分支 |
| 4 | 视频下载 | Plugin | 下载抖音/视频平台内容 |

| 9 | 长文润色 | LLM | 润色优化长文本（5000-10000字） |

## 统一对话流设计

### 对话流 Prompt（融合全部需求）

```
你是一个全能型内容处理助手，具备以下能力：
1. 视频处理：下载抖音视频、视频转文字摘要
2. 文本处理：网页摘要、AI写作、长文润色（5000-10000字）
3. 搜索：必应搜索互联网信息
4. 创作：文生图、历史故事、古风养生文案、婚姻情感文案、新闻资讯
5. 技术：代码生成（128k上下文）、思维导图生成
6. 智能路由：根据用户输入自动判断意图，选择对应处理流程
7. 质量保证：自我反思检查输出质量，模型推荐选择最佳模型

用户输入后，请：
1. 解析输入类型（URL/文本/视频链接/指令）
2. 自动路由到对应处理流程
3. 执行处理并输出结果
4. 自我反思检查质量
5. 如有问题自动修复后重新输出
```

## 部署说明

此设计文档可直接在 Coze 平台手动创建对应的工作流和对话流。每个节点的具体参数需在 Coze 编辑器中配置。
