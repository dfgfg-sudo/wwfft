二、Coze 工作流节点详细配置

第 1 步：开始节点 — 接收主题方向

这是整个工作流的入口，接收用户输入或从外部数据源传入的视频主题。

参数 配置值
节点类型 开始节点
输入变量 zhuti（主题方向，如“智能语音中控屏—一句话控制全屋家电”）
说明 支持手动输入，也可通过定时任务从热点榜单 API 自动传入主题

第 2 步：1 号大模型 — 写图片和视频提示词

参数 配置值
节点类型 大模型节点
模型 豆包·1.8（或 DeepSeek-V3）
输入 {{开始节点.zhuti}}
输出 tupian（图片提示词）、shipin（视频提示词）
参数 seed（固定或随机）

系统提示词（角色设定） ：

你是一位经验丰富且极具创意的商品宣传图生图提示词及视频提示词生成专家。你擅长深入剖析用户提供的商品信息，从独特亮点和目标受众喜好出发，巧妙精准地生成贴合需求的生图提示词，助力打造极具吸引力的商品宣传图。且生成的图片只有 logo，不要有文字出现。 同时，能围绕生图提示词创作出具有商业大片风格的视频提示词，让视频中商品周围的元素“动起来”。

技能 1：生成图片提示词

当用户提供商品信息 {{zhuti}} 时，按以下格式生成：

“广告摄影，商品广告，[具体商品名称]，背景{背景特点描述}，商品醒目地展示在中间，标签清晰可见。商品周围是{周围相关元素描述}，[相关元素状态描述]。背景是（背景颜色），突出了（主题描述），还有[其他元素]，为图像增添了强度。”

约束：图片提示词的背景描述必须与商品相关；生成的图片只有 logo，不能有任何文字出现。

技能 2：生成视频提示词

基于技能 1 生成的图片提示词，生成一个 10 秒的商品宣传视频提示词，包含 3 个不同镜头切换及对应运镜，每个镜头中商品周围的元素都处于“动起来”的状态。

约束：

· 视频提示词只输出提示词内容，不加标头
· 视频提示词控制在 200 字左右
· 运镜方式可自由修改

第 3 步：图像生成

参数 配置值
节点类型 图像生成插件
模型 豆包·4.5 / Seedream 4.5
输入 {{1号大模型.tupian}}
输出 msg（生成的图片数据）
参数 seed

第 4 步：视频生成

参数 配置值
节点类型 视频生成插件
模型 doubao-seedance.dit（或 Seedance 2.0）
输入 {{1号大模型.shipin}}
输出 video msg（生成的视频数据）
参数 seed、duration（10秒）、ratio（16:9 或 9:16）

Seedance 2.0 API 核心参数参考：

参数 类型 说明
model string 模型名称，固定为 doubao-seedance-1-5-pro-251215
duration int 视频时长，4~12 秒，默认 5 秒
ratio string 宽高比，支持 16:9、9:16、1:1 等
resolution string 分辨率，480p/720p/1080p
generate_audio boolean 是否生成同步音频，默认 false
seed int 随机数种子，范围 0~2147483647
watermark boolean 是否含水印，默认 false

Seedance 2.0 具备文字、图片、音频、视频四模态同时理解能力，能基于一张图片生成具备同步音频、多镜头叙事的电影级视频，且支持 8 种以上语言的音素级对口型。

第 5 步：背景音乐生成

参数 配置值
节点类型 SH Music message 插件
输入 keyword（音乐关键词，如“科技感 轻快”）
输出 message（生成的音乐/BGM）
模型 豆包·4.5
参数 seed

第 6 步：剪辑合成视频

参数 配置值
节点类型 [bill_info sitmessage] 视频合成插件
输入 audio（来自第 5 步）、video（来自第 4 步）、is_audio_message
输出 bill_info、sitmessage、sit_feq_id（合成后的最终视频）
模型 豆包·4.5
参数 seed

第 7 步：结束节点

将最终生成的视频输出到指定位置（下载链接 / 云存储 / 直接发布平台）。
