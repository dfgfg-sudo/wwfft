6. 部署与集成指南

6.1 安装插件

1. 打开 Trae-AI-IDE（版本 ≥ 2.5.0）
2. 进入插件市场，搜索 “Coze全域智能自动化平台”
3. 点击 安装，重启 IDE 完成激活

6.2 配置认证（推荐使用 Trae 专用 API 密钥）

1. 登录 Coze 控制台 → Trae 集成 → 生成专用密钥
2. 在 Trae 中：设置 → 插件 → Coze → 粘贴 API 密钥
3. 点击 测试连接 验证配置

6.3 功能验证

· 打开任意代码文件，右键选择 “Coze 代码分析”
· 观察输出面板中的分析报告
· 故意制造一个语法错误，查看是否弹出 错误自愈 建议
