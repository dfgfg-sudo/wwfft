🛡️ 错误处理与日志

· 所有文件处理均包裹在 try-except 中，单个文件失败不影响整体流程。
· 日志同时输出到控制台和 training.log 文件，便于事后排查。
· GUI 日志区域以彩色标签区分错误（红）、成功（绿）、信息（默认黑/蓝）。

📝 注意事项

1. 模型兼容性：务必使用 AutoModelForCausalLM 支持的模型（如 GPT-2、Qwen、LLaMA 等），并确保 model/ 目录包含完整的模型文件。
2. 数据量：知识库容量固定为 1000 条，若数据过多会自动淘汰旧条目（先进先出）。
3. 图像数据：目前仅存储图像张量，不参与文本训练；若需结合多模态，请自行扩展 _prepare_inputs 逻辑。
4. 资源占用：在 CPU 上训练小模型（如 GPT-2 small）约需 2~4 GB 内存，GPU 可大幅加速。
5. 自定义调整：可修改 QuantumTrainer.lora_config 和 train() 中的 epochs 参数以适配不同任务。

项目概述

全功能超融合AI工厂 是一个工业级的自动化机器学习平台，集成了多模态数据处理、零样本训练、动态参数调整、增量学习和自愈系统。它能够监听指定目录中的文本、图像、表格和压缩包文件，自动进行数据标注、模型训练与版本管理，实现全流程的AI自动化。

核心能力

· 🔄 自愈模型验证 – 启动时自动检查模型完整性，损坏自动修复
· 🧠 多模态自动标注 – 文本、图像、表格数据智能打标
· 🚀 动态训练引擎 – 根据数据量自适应调整超参数
· 💾 版本控制系统 – 每次训练自动保存新版本
· 📁 实时文件监控 – 基于Watchdog的事件驱动处理
