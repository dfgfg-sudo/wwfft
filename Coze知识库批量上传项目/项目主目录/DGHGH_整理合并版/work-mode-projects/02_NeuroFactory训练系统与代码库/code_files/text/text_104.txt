## 功能说明

1. **自动化数据收集**：
   - 递归搜索指定目录及其子目录中的所有支持的文件类型
   - 支持的文件类型包括：.txt, .pdf, .csv, .xlsx, .json, .docx, .jpg, .png, .zip
   - 自动解压ZIP文件并处理其中的内容

2. **数据分类存储**：
   - 文本数据（.txt, .pdf, .docx）
   - 表格数据（.csv, .xlsx, .json）
   - 图像数据（.jpg, .png）
   - 文档数据

3. **数据预处理**：
   - 文本数据清洗（标准化、去噪等）
   - 表格数据处理（处理缺失值、去重等）
   - 图像数据处理（格式统一等）

4. **扩展性**：
   - 可以轻松添加对新文件类型的支持
   - 可以自定义各种预处理步骤
   - 模块化设计，便于集成到现有流程中

## 使用建议

1. 根据实际需求调整`DataPreprocessor`中的预处理逻辑
2. 对于大型数据集，考虑添加分批处理功能
3. 可以添加数据增强功能，特别是对于图像和文本数据
4. 考虑添加数据验证步骤，确保数据质量
5. 对于敏感数据，添加适当的加密或匿名化处理
