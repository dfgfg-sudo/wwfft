#### 2.1.5 设计模式应用

| 设计模式 | 应用场景 | 工作流实现 |
|----------|----------|------------|
| **状态模式 (State Pattern)** | 主实体生命周期管理 | 有限状态机节点 |
| **策略模式 (Strategy Pattern)** | 可互换的处理逻辑 | 条件分支网关 |
| **观察者模式 (Observer Pattern)** | 事件驱动通信 | 事件监听器节点 |
| **Saga 模式 (Saga Pattern)** | 分布式事务补偿 | 补偿事务节点 |
| **模板方法模式 (Template Method)** | 工作流骨架定义 | 抽象工作流模板 |
| **责任链模式 (Chain of Responsibility)** | 审批流转 | 顺序审批节点 |
