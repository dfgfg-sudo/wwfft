3. 核心功能模块

模块 功能 技术实现
FileMerger 自动检测并合并相同后缀的重复文件 基于文件内容SHA256哈希分组，保留首个副本
DeepComparator 深度对比文件内容，输出相似度和差异位置 逐字节比较（小文件）/ 抽样比较（大文件）
AutoDatasetCompressor 全自动压缩流水线：扫描→合并→对比→压缩→校验 多线程并行，自适应压缩算法
ZipImageDataset PyTorch数据集接口，直接从ZIP加载图像 懒加载 + LRU缓存
完整性验证 生成SHA256校验文件，支持验证命令 sha256sum 兼容格式
