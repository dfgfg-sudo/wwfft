## 第一部分：GitHub Actions 基础

### 1.1 什么是 GitHub Actions
GitHub Actions 是 GitHub 提供的持续集成与持续部署（CI/CD）平台，允许您在代码仓库中自动化构建、测试和部署流程。它基于事件驱动，支持在 `push`、`pull_request`、`schedule` 或手动触发时执行工作流（Workflow）。

### 1.2 核心概念
- **Workflow**：一个可配置的自动化过程，定义在 `.github/workflows/*.yml` 文件中。
- **Event**：触发 Workflow 的活动，如 `push`、`pull_request`、`workflow_dispatch` 等。
- **Job**：Workflow 中的执行单元，可并行或串行运行。
- **Step**：Job 中的单个任务，可以是 shell 命令或使用预定义的 Action。
- **Action**：可复用的任务单元，例如 `actions/checkout@v4` 用于检出代码。
