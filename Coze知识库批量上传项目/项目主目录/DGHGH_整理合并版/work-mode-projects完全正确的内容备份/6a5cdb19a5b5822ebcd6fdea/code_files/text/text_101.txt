问题 解决方案
GitHub访问失败 配置代理或使用镜像（ghproxy.com）
训练内存不足 减小batch_size，使用梯度累积，混合精度
模型类型不匹配 检查模型配置与数据维度是否对齐
Coze插件配置错误 使用 ParameterFixer 自动修复
循环导入 重组模块，将共同依赖提取到 common.py
pip下载慢 更换国内源（清华、阿里云）
训练失败 alloc_c 降低batch_size或使用CPU模式
