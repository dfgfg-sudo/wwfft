### 2.3 常见场景对比

| 场景 | 本地开发 | GitHub Actions |
|------|----------|----------------|
| 触发方式 | 手动命令 | 事件自动触发 |
| 环境 | 本地操作系统 | 临时 runner（如 ubuntu-latest） |
| 持久化 | 文件永久保存 | 每次运行新环境，需缓存依赖 |
| 交互 | 可交互终端 | 非交互，通过日志输出调试 |
