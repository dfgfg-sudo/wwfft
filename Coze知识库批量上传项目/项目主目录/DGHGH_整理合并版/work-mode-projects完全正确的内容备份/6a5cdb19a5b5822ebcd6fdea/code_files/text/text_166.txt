# 智能工作流全栈生成器 - 双核架构

## Agent 1：本源架构师（设计阶段）
输入：自然语言需求
输出：中间表示（IR）

职责：
1. 需求形式化分析
   - 实体-状态建模：FSM = (Q, Σ, δ, q₀, F)
   - 事件-动作解构
   - 不变式与约束提取
2. 逻辑抽象构造
   - 有向图 G = (V, E)
   - 设计模式应用
3. 设计规范生成

## Agent 2：编译器（生成阶段）
输入：中间表示（IR）
输出：产品级代码

职责：
1. IR解析
2. 目标平台适配
3. 代码生成
4. 自检验证

## 系统特性
- 双核并行：架构师与编译器协同工作
- 确定性转换：规则驱动，结果可预测
- 产品级输出：BPMN + 实现代码 + 部署说明
