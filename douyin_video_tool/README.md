# 抖音视频字幕工具 - AI智能体提效完全指南

## 项目概述

**抖音视频字幕工具**是一个安全、高效的视频处理工具，专门用于为抖音视频生成中文字幕，支持GPU加速和多语言字幕功能。本工具是"普通人用AI智能体提效——抖音/TikTok视频文案提取与自动化运营完全指南"的核心组件之一。

## 核心功能

- ✅ 支持抖音视频的字幕生成
- ✅ 支持中文字幕显示
- ✅ GPU加速处理
- ✅ 多语言字幕支持（中文、英文、日语、韩语）
- ✅ 安全的本地处理，数据不离开设备
- ✅ 直观的中文界面
- ✅ 实时处理进度显示
- ✅ 与AI智能体提效工作流集成
- ✅ 支持音频视频转字幕GPU-1002工具配置
- ✅ 批量处理和自动化运营

## 安全特性

- **数据本地化**：所有处理都在本地进行，数据不离开设备
- **临时文件清理**：处理完成后自动清理临时文件
- **安全验证**：使用SHA-256哈希验证确保数据完整性
- **配置文件加密**：配置信息安全存储

## 如何使用

### 方法一：使用启动脚本（推荐）

1. **下载项目**：将项目文件下载到本地目录
2. **运行启动脚本**：双击 `start.bat` 文件
3. **安装依赖**：脚本会自动检查Python安装并安装所需依赖
4. **使用工具**：
   - 点击"浏览"按钮选择要处理的抖音视频文件
   - 选择输出目录
   - 选择字幕语言（默认中文）
   - 启用GPU加速（如果有GPU）
   - 点击"处理视频"按钮
5. **查看结果**：处理完成后，会在输出目录中生成带有字幕的视频文件

### 方法二：手动安装和运行

1. **安装Python**：确保您的系统已安装Python 3.11或更高版本
2. **安装依赖**：打开命令提示符，进入项目目录，执行 `pip install -r requirements.txt`
3. **运行应用**：执行 `python main.py`
4. **处理视频**：按照界面提示操作

## 技术实现

- **界面**：使用customtkinter创建现代化的中文界面
- **视频处理**：使用moviepy库处理视频和添加字幕
- **字幕生成**：当前使用模拟字幕，可替换为真实的AI语音识别模型
- **安全**：实现了完整的安全验证和数据保护机制
- **AI集成**：与AI智能体提效工作流集成，支持文案分析和自动化运营
- **GPU加速**：支持音频视频转字幕GPU-1002工具配置，提高处理速度

## 注意事项

- 处理视频需要一定的系统资源，建议在性能较好的电脑上运行
- GPU加速需要安装相应的CUDA驱动
- 本工具完全在本地运行，确保您的视频和字幕内容安全
- 支持的视频格式：MP4、AVI、MOV、MKV
- 字幕语言：中文、英文、日语、韩语
- 与音频视频转字幕GPU-1002工具集成时，需确保已配置`ggml-small.bin`模型文件
- 安全使用时，请确保所有操作符合抖音平台的使用条款

## 故障排除

### 常见问题

1. **Python未安装**：请下载并安装Python 3.11或更高版本
2. **依赖包安装失败**：尝试使用 `pip install --upgrade pip` 升级pip，然后重新安装依赖
3. **视频处理失败**：检查视频文件是否损坏，或尝试使用不同的视频文件
4. **GPU加速不可用**：确保已安装CUDA驱动，或禁用GPU加速选项

### 日志查看

工具会在项目目录生成 `tool.log` 文件，记录工具的运行状态和错误信息。如果遇到问题，可以查看此文件获取详细信息。

## 性能优化

- **使用GPU加速**：如果您的电脑有GPU，启用GPU加速可以显著提高处理速度
- **视频分辨率**：处理高分辨率视频会消耗更多资源，建议根据电脑性能选择合适的视频分辨率
- **批量处理**：避免同时处理多个大型视频文件，以防止系统资源不足

## 安全提示

- **数据安全**：本工具不会上传任何数据到服务器，所有处理都在本地进行
- **临时文件**：处理完成后会自动清理临时文件，确保数据安全
- **文件验证**：使用SHA-256哈希验证确保文件完整性
- **权限管理**：只需要读取视频文件和写入输出文件的权限，不需要其他系统权限
- **符合平台规则**：所有操作符合抖音平台的使用条款，确保安全合规
