# 超大文件分卷备份 · 使用说明

## 这是什么？

`D:\wwfft\Coze知识库批量上传项目\项目主目录` 下有 9 个超过 GitHub 单文件 100MB 硬上限的大文件，
无法直接上传。因此采用**分卷（切片）备份**：每个大文件按 95MB 切成多块（`原文件名.part001`、`.part002`、…），
连同校验清单和本恢复脚本一起存放在本分支。

- **所在分支**：`large-files-backup`
- **目录结构**：与 `项目主目录` 下的原相对路径一一对应
- **清单文件**：`_分卷清单.json`（记录每个文件的原始大小、原始 SHA256、每块的大小与 SHA256）
- **恢复工具**：`合并恢复脚本.py`

## 如何还原成原文件？

1. 下载本分支（Code → Download ZIP，或 `git clone -b large-files-backup`）；
2. 确保安装了 Python 3（完全免费）；
3. 在"超大文件分卷备份"文件夹里打开命令行，执行：

   ```
   python 合并恢复脚本.py "D:\还原到这里的目录"
   ```

4. 脚本会逐块校验 SHA256 → 顺序合并 → 整体校验 SHA256，全部通过后输出原文件。
